# DateArc — генератор свиданий

Интерактивный веб-приложение для планирования идеального свидания за 6 шагов.

## Что внутри

| Шаг | Что делает |
|-----|------------|
| 1. Роли | Кто инициатор, кто партнёр |
| 2. Вайб | Настроение свидания (романтика, приключение и т.д.) |
| 3. Локация | Поиск мест через Яндекс Карты |
| 4. Дата и время | Выбор даты и тайм-слота |
| 5. Дресс-код | Подбор стиля одежды |
| 6. Приглашение | Генерация красивого инвайта (картинка) |

## Стек

- React 19 + Vite
- Lucide React (иконки)
- date-fns (даты)
- html-to-image (экспорт приглашения)
- Vitest + Testing Library (тесты)

## Запуск

```bash
npm install
npm run dev
```

## Переменные окружения

Создайте `.env` на основе `.env.example`:

```env
VITE_YANDEX_MAPS_API_KEY=ваш_ключ
VITE_LOOK_ADS_ENABLED=false
```
